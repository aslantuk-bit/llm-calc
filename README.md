# Калькулятор железа для локальных LLM

Одна страница `index.html`: открыть двойным щелчком, работает офлайн, без установки.

Слева задаёшь модель (пресет или свою), квантование, контекст, желаемую скорость.
Справа железо: пресет (текущие Mac по продуктам, прошлые чипы Apple, коробки на NVIDIA GB10 и AMD Strix Halo, Jetson, мини-ПК на Intel/AMD/Qualcomm, дискретные карты, серверы, чистый процессор) или свои числа. Внизу сразу два ответа:

- **Минимум под модель** — память, пропускная способность, TFLOPS, диск.
- **Прогноз на выбранном железе** — влезает ли, токены/с генерации, скорость обработки промпта, максимальный контекст, вердикт цветом, затем **узкое место** (память / выгрузка / пропускная способность / вычисления) и советы с посчитанными числами: какой квант влезет, сколько даст KV в Q8, поможет ли поднять лимит GPU на Mac, сколько даст MoE с экспертами в ОЗУ, какое железо закроет цель.

## Формулы

- Память = параметры × бит на вес ÷ 8 + KV на токен × контекст + накладные (0,75 ГБ + 4 % весов + буфер под контекст, с flash attention).
- KV на токен = 2 × слои × KV-головы × размер головы × байт. MLA (DeepSeek, Kimi, GLM-5, Mistral Small 4) хранит один вектор вместо пары, скользящее окно (Gemma, GPT-OSS, Llama 4, MiMo, Laguna) держит в локальных слоях только окно, гибриды (Qwen 3.5+, Nemotron 3, Kimi K3, Granite 4) держат KV только в слоях полного внимания (`kvLayers`), DeepSeek V4 хранит ~10 % кэша (`kvScale`).
- Генерация ≈ пропускная способность × 0,7 ÷ байт на токен, где байт на токен = активные веса + KV-кэш. У MoE считаются только активные параметры.
- Обработка промпта ≈ TFLOPS × 0,5 ÷ (2 × активные параметры).
- Mac отдаёт GPU 2/3 памяти при ≤36 ГБ и 3/4 выше. При нехватке видеопамяти на дискретной карте слои выгружаются в ОЗУ, время на токен складывается пропорционально долям.

## Откуда числа

Архитектуры моделей 2026 года (Qwen 3.5/3.6/3.8, Gemma 4, DeepSeek V4, GLM-5.x, Kimi K2.6/K3, MiniMax M2.7/M3, Mistral Small 4 / Medium 3.5, Nemotron 3, Laguna, MiMo, Ring, OLMo 3) взяты из `config.json` на Hugging Face 13.09.2026. Две записи помечены как оценка: Mistral Large 3 (конфиг закрыт) и число активных параметров у Gemma 4 E2B/E4B. Не включены модели, существование которых не удалось подтвердить на Hugging Face (Llama 5, Phi-5, Qwen3.8-180B).

Железо: спецификации Apple (Mac mini, Mac Studio, MacBook Pro/Air, iMac по состоянию на сентябрь 2026, включая M5 Pro/Max/Ultra и M6), NVIDIA (GB10-коробки, Jetson, DGX Station), AMD (Strix Halo и клоны), Intel Panther Lake, Qualcomm X2 Elite. TFLOPS у M5/M6 — оценка ×2 к M4-аналогу.

## Разработка

Файл собирается из трёх частей, чтобы формулы можно было тестировать без браузера:

```
ui-head.html + calc-block.js + ui-tail.html  →  ./build.sh  →  index.html (и сразу node test.js)
```

Править `calc-block.js` (формулы, пресеты моделей и железа), `ui-*.html` (интерфейс), потом `./build.sh`.
Тесты в `test.js` читают формулы прямо из собранного `index.html`.
