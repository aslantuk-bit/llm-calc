# Калькулятор железа для локальных LLM

Одна страница `index.html`: открыть двойным щелчком, работает офлайн, без установки.

Слева задаёшь модель (пресет или свою), квантование, контекст, желаемую скорость.
Справа железо: пресет (текущие Mac по продуктам, прошлые чипы Apple, коробки на NVIDIA GB10 и AMD Strix Halo, Jetson, мини-ПК на Intel/AMD/Qualcomm, дискретные карты, серверы, чистый процессор) или свои числа, и **оболочка** — движок, которым модель запускается: «Авто» выбирает лучшую для этого железа. Внизу сразу два ответа:

- **Минимум под модель** — память, пропускная способность, TFLOPS, диск.
- **Прогноз на выбранном железе** — влезает ли, токены/с генерации, скорость обработки промпта, максимальный контекст, вердикт цветом, затем **узкое место** (память / выгрузка / пропускная способность / вычисления) и советы с посчитанными числами: какой квант влезет, сколько даст KV в Q8, поможет ли поднять лимит GPU на Mac, сколько даст MoE с экспертами в ОЗУ, какое железо закроет цель.

## Оболочки

Оболочка меняет требования к железу: куда кладётся то, что не влезло в видеопамять, какой KV-кэш доступен, работает ли MTP-голова модели.

| Оболочка | Где работает | Что не влезло — куда | Особенности |
|---|---|---|---|
| llama.cpp (Ollama, LM Studio) | везде | слои или эксперты MoE в ОЗУ | MTP с мая 2026, на Mac без выигрыша |
| MLX / MTPLX | только Mac | — (память общая) | MTP ×1,6–2,7; n-gram-таблицы Flash-Next на SSD |
| vLLM / SGLang | NVIDIA, AMD, Intel | — | занимает 90 % видеопамяти; KV в FP8, NVFP4, TurboQuant 3 бит |
| KTransformers / ik_llama.cpp | NVIDIA, AMD (дискретные) | эксперты MoE в ОЗУ, их считает процессор | для больших MoE на одной карте |
| Strata | NVIDIA, AMD, Intel, Mac; карта от 12 ГБ | эксперты в ОЗУ, n-gram/Engram на SSD | только Qwen3.8-Flash-Next, Qwen3.6, DeepSeek V4.1 Flash |
| Подкачка с SSD (flash-moe, AirLLM) | везде, только MoE | эксперты читаются с SSD, горячие — в памяти | модели больше памяти, но единицы ток/с |

## Формулы

- Память = параметры × бит на вес ÷ 8 + KV на токен × контекст + накладные (0,75 ГБ + 4 % весов + буфер под контекст, с flash attention).
- KV на токен = 2 × слои × KV-головы × размер головы × байт. MLA (DeepSeek, Kimi, GLM-5, Mistral Small 4) хранит один вектор вместо пары, скользящее окно (Gemma, GPT-OSS, Llama 4, MiMo, Laguna) держит в локальных слоях только окно, гибриды (Qwen 3.5+, Nemotron 3, Kimi K3, Granite 4) держат KV только в слоях полного внимания (`kvLayers`), DeepSeek V4 хранит ~10 % кэша (`kvScale`).
- Время на токен = байт на токен ÷ (пропускная способность × 0,7) + слои × задержка на слой (0,19 мс Mac, 0,09 видеокарты; при выгрузке ещё 0,07 Strata, 0,15 KTransformers, 0,3 llama.cpp). Байт на токен = активные веса + KV-кэш. MTP-голова в поддерживающей оболочке — ×1,6.
- Обработка промпта ≈ TFLOPS × 0,5 ÷ (2 × активные параметры + внимание), внимание = 2 × скрытая × длина промпта на слой (в слоях с окном — не больше окна).
- Mac отдаёт GPU 2/3 памяти при ≤36 ГБ и 3/4 выше; GB10 и Jetson — 90 %, Gorgon Halo — 160 из 192 ГБ.
- Выгрузка: слоями (время складывается пропорционально долям) или экспертами MoE (на GPU внимание, ~40 % активных весов и KV, свободная видеопамять — под часть экспертов, остальные из ОЗУ; промпт гоняет экспертов по PCIe). Подкачка с SSD: попадание в кэш горячих экспертов = (доля кэша)^0,2.
- Ревизия 01.11.2026 по замерам (llama.cpp discussions #4167, #16578, #19890, README Strata и MTPLX, flash-moe): gpt-oss-120b на M5 Max — 69 против 75–79 в замере (раньше калькулятор давал 129), Qwen3.5-35B-A3B на RTX 5090 — 198 против 194, на RTX 3060 с экспертами в ОЗУ — 35 против 41, Strata на RTX 5070 — 71 против 94, flash-moe на M3 Max — 6,5 против 4,4. Добавлены кванты MLX 4/8-bit, NVFP4, AWQ/GPTQ, IQ4_XS, UD-Q4_K_XL, IQ3_XXS; KV Q8_0/Q4_0 считаются как 8,5/4,5 бита. MTP-головы сверены по config.json.
- Сборки и калибровка Mac 01.11.2026: блок «Готовые сборки» для Qwen3.8-Flash-Next — 21 сборка (MTPLX, mlx-community, Ollama, Unsloth GGUF, AtomicChat, NVFP4, FP8) с размерами из Hugging Face и KLD Unsloth; на выбранном железе — скорость при 32K/128K/256K и наибольший контекст, отдельно с лимитом GPU, поднятым через sysctl. Сверка на M5 Max 128 ГБ: MTPLX Optimized Speed — 66 и 55 ток/с против 61,8 (109K) и 50,3 (200K); Strata UD-Q4_K_XL — 90 против 94. Подкачка с SSD у Strata на Mac пересчитана (попадание в кэш = доля^0,9): DeepSeek V4.1 Flash 2,25 бита — 16 ток/с против 13–17,6 в замере (было 40). Flash-Next — 180B по карточке (было 176B).

## Откуда числа

Архитектуры моделей 2026 года (Qwen 3.5/3.6/3.8, Gemma 4, DeepSeek V4, GLM-5.x, Kimi K2.6/K3, MiniMax M2.7/M3, Mistral Small 4 / Medium 3.5, Nemotron 3, Laguna, MiMo, Ring, OLMo 3) взяты из `config.json` на Hugging Face 13.09.2026. 20.10.2026 добавлены DeepSeek V4.1 Flash, MiMo-V2.6 Pro/Flash, Step 5 Preview, Nemotron 3.5 (Lightning, Bolt, Super VL), Meta Muse Spark Open, Reflection Beam 1.0, Marin Snowball. 01.11.2026 добавлены Mistral Large 4 и MiniMax-M3.1-Flash (веса вышли 23–29.10), Ling-3.0-flash-VL, LFM3 1.7B, Nemotron-Labs Dory 4B; железо: DGX Spark и GB10-коробки 64 ГБ, Framework Desktop 192 ГБ (AI Max+ PRO 495), Intel Arc Pro B70, поправлена пропускная способность Snapdragon X2 Elite (152 ГБ/с). Qwen3.7 Plus и Kimi K3.1 Pro не включены: на 01.11.2026 их весов нет на Hugging Face. Две записи помечены как оценка: Mistral Large 3 (конфиг закрыт) и число активных параметров у Gemma 4 E2B/E4B. Не включены модели, существование которых не удалось подтвердить на Hugging Face (Llama 5, Phi-5, Qwen3.8-180B).

Железо: спецификации Apple (Mac mini, Mac Studio, MacBook Pro/Air, iMac по состоянию на сентябрь 2026, включая M5 Pro/Max/Ultra и M6), NVIDIA (GB10-коробки, Jetson, DGX Station), AMD (Strix Halo и клоны), Intel Panther Lake, Qualcomm X2 Elite. TFLOPS у M5/M6 — оценка ×2 к M4-аналогу; по замерам llama.cpp на коротких плотных моделях M5 Max обрабатывает промпт в ~3,5 раза быстрее M4 Max, но на MoE (gpt-oss-120b, 16,7K за 12 с) текущее число совпадает с замером, поэтому оставлено.

## Разработка

Файл собирается из трёх частей, чтобы формулы можно было тестировать без браузера:

```
ui-head.html + calc-block.js + ui-tail.html  →  ./build.sh  →  index.html (и сразу node test.js)
```

Править `calc-block.js` (формулы, пресеты моделей и железа), `ui-*.html` (интерфейс), потом `./build.sh`.
Тесты в `test.js` читают формулы прямо из собранного `index.html`.
